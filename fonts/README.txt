Fonts served from our own site (instead of Google Fonts), so the app opens faster
and works offline. Files are the exact woff2 files Google Fonts serves, Hebrew and
Latin subsets only.

Frank Ruhl Libre (weights 500-700, one variable file per subset)
  Copyright 2015 The Frank Ruhl Libre Project Authors (https://github.com/fontef/frankruhllibre)
  Source: https://fonts.google.com/specimen/Frank+Ruhl+Libre

IBM Plex Sans Hebrew (weights 400, 500, 600)
  Copyright 2017 IBM Corp. with Reserved Font Name "Plex"
  Source: https://fonts.google.com/specimen/IBM+Plex+Sans+Hebrew

Both are licensed under the SIL Open Font License, Version 1.1
(https://openfontlicense.org). Full text:
  https://github.com/google/fonts/blob/main/ofl/frankruhllibre/OFL.txt
  https://github.com/google/fonts/blob/main/ofl/ibmplexsanshebrew/OFL.txt

Changing a font file: give the new file a new name (the service worker keeps
files by name), and update the list in sw.js and the @font-face rules at the
top of style.css.
